Betterfly2 网关

所有站点与接口统一从这个地址进入，按路径分发到各个服务。

客户端与开放接口

消息长连接
WebSocket + Protobuf，负载均衡到所有 DataForwarding 实例
文件服务
/storage_service/
上传、校验与下载签名；文件内容经网关直达对象存储
实验配置
/abtest/v1/
客户端实验配置与服务端求值
好友动态
/moments/
网页版动态与原生客户端共用的 API
Bot API
/bot/v1/
第三方机器人长轮询、发消息与文件
群通话信令
LiveKit 信令；媒体仍走 7881/7882 与 Coturn

管理后台

推送后台
/push/admin/
APNs 设备、审计与调试发送
实验后台
/abtest/admin/
实验配置、推全与撤回
机器人管理
/chatbot/admin/
创建机器人、重置令牌、开关群聊

运维工具

网关控制台
/dashboard/
Traefik 路由、服务与实例状态
Grafana
/grafana/
监控面板（observability）
Prometheus
/prometheus/
指标查询与告警规则（observability）
Kafka UI
/kafka-ui/
Topic、消费组与消息查看（tools）

管理后台与运维工具只接受本机和内网来源，范围由 GATEWAY_ADMIN_SOURCE_RANGE 配置； 各后台自己的令牌或登录照常生效。绿点表示该路由当前已在网关上注册，灰点表示对应服务未启动。
